# 🧹 Data Cleaning Project — Employee Dataset

A complete data cleaning project using **Python, NumPy, and Pandas**. This project demonstrates how to handle messy real-world data — missing values, duplicates, outliers, and inconsistent formatting.

---

## 📊 What This Project Does

- ✅ Loads a messy employee dataset
- ✅ Handles missing values (mean/median imputation)
- ✅ Removes duplicate records
- ✅ Detects and handles outliers using IQR
- ✅ Cleans and standardizes column formats
- ✅ Exports a cleaned dataset

---

## 🛠️ Technologies Used

- Python 3
- NumPy — numerical operations
- Pandas — data manipulation
- Jupyter Notebook — development environment

---

## 📂 Dataset

- **File:** `Messy_Employee_dataset.csv`
- **Description:** A synthetic messy employee dataset for practicing data cleaning.

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abdul-rafay-dev0/Data-Cleaning-Project.git
   ```
2. Install dependencies:
   ```bash
   pip install pandas numpy jupyter
   ```
3. Open the notebook:
   ```bash
   jupyter notebook Project.ipynb
   ```
4. Run all cells to see the cleaning process.
